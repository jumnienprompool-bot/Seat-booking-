# SeatFlow V2 — ระบบจองที่นั่งห้องเรียน (วิทย์-คณิต)

ระบบจองที่นั่งแบบมีเวลาจำกัด จองได้ 1 ครั้งต่อคน ธีมฟ้าเทคโนโลยี
เขียนด้วย Node.js + Express เก็บข้อมูลในไฟล์ `data.json`

## ฟีเจอร์
1. ✅ แอดมินกด **เริ่มการจอง** → นับถอยหลัง 5 วินาที → เปิดจอง 10 นาที → ปิดระบบอัตโนมัติ
2. ✅ แต่ละคนจองได้ **ครั้งเดียวเท่านั้น** (เช็คจากชื่อเล่น + อุปกรณ์) ถ้าพยายามจองซ้ำจะเด้ง popup แจ้งเตือนทันที
3. ✅ ที่นั่งที่ถูกจองไปแล้วแสดง **สีแดง** คนอื่นกดจองไม่ได้
4. ✅ รายชื่อผู้จองไปยังแอดมินทันที แสดงเป็น **ผังการจองสด** บนที่นั่ง (มีชื่อ) ง่ายต่อการดู + มีตารางรายชื่อ
5. ✅ ปิดระบบทันทีเมื่อเวลาหมด ไม่มีเงื่อนไขใดๆ (server-side validation)
6. ✅ ธีมสีฟ้าแนวเทคโนโลยี ห้องเรียนวิทย์-คณิต
7. ✅ รหัสแอดมิน: `zxcvbnm`

## หน้าต่างๆ
- `/` — หน้าจองที่นั่ง (นักเรียน)
- `/summary.html` — หน้าสรุปผังที่นั่ง (สาธารณะ)
- `/admin-login.html` — เข้าระบบแอดมิน
- `/admin.html` — แดชบอร์ดแอดมิน (เริ่ม/ปิด/รีเซ็ต ระบบ, วางผังที่นั่ง, ดูผังการจองสด, รายชื่อ)

## วิธีรันบนเครื่องตัวเอง

```bash
# เปิด http://localhost:3000
```

## วิธี Deploy ขึ้น GitHub + Render (ฟรี)

### ขั้นตอนที่ 1: สร้าง Repo บน GitHub
1. ไปที่ https://github.com/new สร้าง repo ใหม่ (เช่น `seatflow-v2`) **ไม่ต้อง**ติ๊ก README
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลากวางบนหน้า GitHub หรือใช้ git):
   ```bash
   git init
   git add .
   git commit -m "SeatFlow V2"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/seatflow-v2.git
   git push -u origin main
   ```

### ขั้นตอนที่ 2: Deploy บน Render
1. ไปที่ https://render.com → สมัคร/เข้าสู่ระบบด้วย GitHub
2. กด **New +** → **Web Service**
3. เลือก repo `seatflow-v2` ที่เพิ่งสร้าง
4. ตั้งค่า:
   - **Name:** `seatflow-v2` (อะไรก็ได้)
   - **Region:** Singapore (ใกล้ไทยสุด)
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. กด **Create Web Service** รอประมาณ 2-3 นาที จะได้ URL เช่น `https://seatflow-v2.onrender.com`
6. เปิด URL นั้น ใช้งานได้เลย! เข้าแอดมินที่ `/admin-login.html` รหัส `zxcvbnm`

### ขั้นตอนที่ 3: วางผังที่นั่ง (ครั้งแรก)
1. เข้าแอดมิน → แท็บ **จัดการผังที่นั่ง**
2. กด **สร้างแบบแถว** (ใส่จำนวนแถว×คอลัมน์) หรือกด **+ เพิ่มที่นั่ง** ทีละตัว แล้วลากวาง
3. ดับเบิลคลิกที่นั่งเพื่อเปลี่ยนชื่อ/รหัส กด × มุมขวาบนเพื่อลบ
4. กด **💾 บันทึกผังที่นั่ง**

### ขั้นตอนที่ 4: เริ่มการจอง
1. แท็บ **ผังการจองสด** → กด **▶ เริ่มการจอง**
2. ระบบจะนับถอยหลัง 5 วิ แล้วเปิดจอง 10 นาที นักเรียนเปิด URL เดียวกันจองได้พร้อมกัน
3. เมื่อครบ 10 นาที ระบบปิดอัตโนมัติทันที

## หมายเหตุ
- Render ฟรีจะ "หลับ" เมื่อไม่มีคนใช้งาน ครั้งแรกที่เปิดเว็บอาจช้า 30-60 วินาที (รอเซิร์ฟเวอร์ตื่น) เป็นเรื่องปกติ
- ข้อมูลการจองเก็บใน `data.json` บนเซิร์ฟเวอร์ ถ้ากด **รีเซ็ต** หรือ deploy ใหม่ ข้อมูลจะหายไป (เหมาะกับใช้ต่อคาบ/ต่อวัน)
- เปลี่ยนรหัสแอดมิน/เวลาได้ที่ไฟล์ `server.js` ตัวแปร `ADMIN_CODE`, `COUNTDOWN_SECONDS`, `OPEN_SECONDS`
